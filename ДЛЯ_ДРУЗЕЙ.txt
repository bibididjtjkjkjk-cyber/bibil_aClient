bibil_aClient — как запустить и поиграть вместе
==============================================

1. Установка (Windows 10/11, 64-bit):
   - Вариант А: запустите «bibil_aClient-Setup-1.1.1.exe» — обычная установка.
   - Вариант Б: запустите «bibil_aClient-1.1.1.exe» — версия без установки, можно просто скопировать файл.
   - Иконка программы (в панели задач и в установщике) — та же аватарка, что и в Discord.
   - ОБЕ версии (Setup и portable) обновляются САМИ: адрес вводить не нужно, он вшит в сборку.
     Лаунчер проверяет GitHub Releases, а при недоступности — зеркало
     https://bibil-updates-production.up.railway.app/.
     При запуске он покажет новую версию, скачает её с прогрессом и заменит файл при выходе;
     если антивирус ругается — добавьте папку лаунчера в исключения.
   - Язык интерфейса: «Настройки» → «Оформление» → «Язык интерфейса»: Русский / Українська / English.
   - Вкладка «Косметика»: плащи, крылья, эффекты, скины, аксессуары и пресеты. Выбор сохраняется
     отдельно для каждого профиля; каталог можно обновить кнопкой «Обновить каталог».

2. Первый запуск:
   - Локальный аккаунт (Player####) создаётся автоматически — ничего настраивать не нужно.
   - Нажмите «Играть» (или «Быстрый старт»). Первый раз скачиваются игра, библиотеки и Java:
     это может занять 5–15 минут и несколько ГБ места.
   - Если игра вылетела: нажмите кнопку «Безопасно» на главной — она запускает чистую ваниль
     без модов, ресурспаков и пользовательских аргументов. Причина вылета показывается на главной.
   - «Настройки» → «Сбросить настройки» возвращает безопасные значения.
   - В консоли могут появляться ошибки 401 / Realms / «Failed to fetch user properties» —
     это нормально для локального аккаунта без лицензии: игра от этого не вылетает,
     просто не работают скины и Realms.
   - ВАЖНО (краш на AMD): Minecraft 26.3 сам выбирает Vulkan и после неудачного старта
     переключается на «Default», что на AMD Radeon снова дает Vulkan и вылет 0xC0000005
     в amdvlk64.dll. Лаунчер перед каждым запуском принудительно пишет в options.txt
     preferredGraphicsBackend:"opengl" — это лечит краш. Менять можно в
     «Настройки» → «Игра» → «Графический бэкенд». Если вам нужен Vulkan — обновите Radeon Software.
   - Свежий hs_err_pid*.log разбирается лаунчером автоматически: причина краша появится
     на главной (например, «Краш драйвера Vulkan AMD»).
   - Предупреждения про System::load / sun.misc.Unsafe в консоли — безвредны; лаунчер
     добавляет флаги Java 25, чтобы их убрать. На краш они не влияют.
   - Если вылет повторяется (код 3221225477): лаунчер сам повторит запуск до 2 раз
     в безопасном режиме (выключается: «Настройки» → «Повтор запуска после краша JVM»).
     Попробуйте другую сборку Java 25 (Microsoft OpenJDK / свежий Eclipse Temurin)
     и выключите оверлеи GeForce Experience / Discord / MSI Afterburner.
     Подробности — «Консоль» и logs\game-*.log в папке лаунчера.

3. Чтобы играть вместе (без лицензии и без Microsoft):
   - Установите Hamachi или ZeroTier и объединитесь в одну виртуальную сеть.
   - Один игрок: создаёт/открывает мир → «Открыть в локальную сеть».
   - Остальные: «Мультиплеер» → подключаются по IP из Hamachi/ZeroTier.
   - У всех должны совпадать версия Minecraft, загрузчик и набор модов/ресурспаков.
     Папку профиля можно просто скопировать: %APPDATA%\bibil_aClient\instances\<id>\

4. Официальные серверы:
   - Нужен лицензионный Minecraft: Java Edition и вход через Microsoft.
   - Для входа нужен Azure Application (client) ID: он пока не вшит в сборку.
     Введите его в лаунчер: «Настройки» → «Вход в аккаунт» → Azure Application (client) ID,
     либо попросите у автора сборки ID для этой сборки.

5. Ресурспаки:
   - Ставятся только в разделе «Ресурспаки» (папка resourcepacks профиля),
     НЕ в папку mods — иначе Minecraft вылетает.
   - Лаунчер показывает несовместимые с версией игры паки и может их выключить.

6. Discord (необязательно): чтобы было видно, во что играете
   - discord.com/developers → New Application (название, например bibil_aClient).
   - Rich Presence → Art Assets: загрузите файл discord-avatar.png (лежит в этом архиве,
     это та же аватарка, что и иконка самой программы) с ключом  logo .
   - Скопируйте Application ID приложения в Настройки → Discord лаунчера.
   - Наведите на картинку в статусе: там будет «Играет в Minecraft 26.3 …».
   Без Application ID и загруженного ассета Discord не покажет картинку — это его требование.

Если что-то не работает: нажмите «Консоль» в лаунчере и скопируйте последние строки ошибки автору.
